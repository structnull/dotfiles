# Quickshell modernization and optimization report

## Implementation status

- Tray submenus, check states and menu-only items now use the native menu API. Bar popups keep their existing layer styling and use the invoking output and screen-local placement. The popup and tray open with their borders inside the window surface. Shared buttons and sliders gained keyboard actions. [Tray menu](components/TrayMenu.qml), [popup window](components/QsPopupWindow.qml), [slider](components/QsSlider.qml).
- Wi-Fi discovery runs while its pages or a connection attempt need it. The native connection result controls password prompts and errors. Bluetooth discovery follows adapter state. Quick Settings releases radio, audio, and OSD ownership on close. [Wi-Fi](services/NetworkService.qml), [Bluetooth](services/BluetoothService.qml), [Quick Settings](modules/quickSettings/QuickSettingsWindow.qml).
- Notification toasts are capped at five. Reloaded records restore to history without replaying, transient records are released at expiry, and notification actions now reach the sender. History ages use the shared minute clock. [Notifications](services/NotificationService.qml), [notification cards](modules/notifications/NotificationCard.qml).
- Wallpaper changes serialize application and palette generation. Mutable state moves to the per-shell XDG state directory, with the original file used as a migration seed. Logout targets the graphical session, and Polkit input follows the active challenge. [Wallpaper](services/WallpaperService.qml), [state](services/StateService.qml), [power](services/PowerService.qml), [Polkit overlay](modules/polkit/PolkitOverlay.qml).
- Non-default PipeWire tracking is scoped to the Audio page, media progress uses the native MPRIS position, and the calendar owns its seconds clock. Telemetry queries now select the discovered backlight and GPU, and network rates use per-interface deltas. [Audio](services/AudioService.qml), [media](services/MprisService.qml), [brightness](services/BrightnessService.qml), [system monitor](services/SystemMonitorService.qml).

**Verified:** isolated Quickshell tests covered legacy state migration, rapid wallpaper requests and a failed apply, panel and overlay startup, Wi-Fi and Audio page lifetimes, overlapping OSD suppression, notification burst limits, and transient notification release. The window tests used a private virtual X display and private D-Bus session, with Wayland-only assignments removed from the test copy.

**Still to verify on the desktop:** mixed-scale and negative-origin monitor geometry, native tray menus from real apps, radio and audio device transitions, Polkit prompts, backlight and GPU behavior on the target hardware, and Hyprland frame-time and memory measurements. Further renderer and cache changes depend on those measurements. The audit below retains the original pre-implementation code locations.

Audited the current Quickshell worktree on 19 November 2026 against the [Quickshell 0.3.2 usage guide](https://quickshell.org/docs/v0.3.2/guide/), versioned API reference, and Qt 6.12 documentation. The installed versions are Quickshell 0.3.2 and Qt QML tooling 6.12.0. The review covers the shell entry point, services, bar, popups, overlays, shared controls, shaders, and their Hyprland and Matugen integration.

The highest-value work is to correct tray menu handling, make Wi-Fi and Bluetooth operations follow their native state, fix popup geometry on secondary monitors, and serialize wallpaper and palette changes. The best candidates for reducing idle work are Wi-Fi discovery, the global seconds clock, and unneeded PipeWire subscriptions. Existing native integrations already cover most services.

| Order | Work | Expected payoff |
| --- | --- | --- |
| 1 | Tray menu contract, Wi-Fi connection flow, monitor-local popup placement, notification lifecycle, wallpaper apply queue, session-scoped logout | Correctness on ordinary desktop paths |
| 2 | Isolate persistent state and make OSD suppression owner-aware | Predictable reloads, test instances, and multi-monitor interaction |
| 3 | Gate radio scans, PipeWire tracking, and second-level clock updates | Lower background work and less radio activity |
| 4 | Profile popup construction, render paths, and sensor work on the desktop | Evidence for further latency and memory improvements |
| 5 | Add a lint baseline and improve shared controls | Fewer regressions in QML bindings, layout, and keyboard interaction |

## P1 · Correctness and lifecycle

### Use the native tray menu contract

[TrayMenu.qml:49](components/TrayMenu.qml) and [TrayMenu.qml:208](components/TrayMenu.qml) look for members such as `menu`, `children`, `toggleType`, and `checked` on menu entries. In 0.3.2, the entry itself is a menu handle. Its documented fields are `hasChildren`, `isSeparator`, `enabled`, `buttonType`, and `checkState`, and its activation method is `triggered()`. Pass a submenu entry directly to `QsMenuOpener.menu`. Render radio, checkbox, indeterminate and disabled states. A `QsMenuAnchor` pilot could remove the custom tree traversal if its platform styling suits the bar. [QsMenuEntry](https://quickshell.org/docs/v0.3.2/types/Quickshell/QsMenuEntry/), [QsMenuOpener](https://quickshell.org/docs/v0.3.2/types/Quickshell/QsMenuOpener/), [QsMenuAnchor](https://quickshell.org/docs/v0.3.2/types/Quickshell/QsMenuAnchor/).

[TrayWidget.qml:224](components/TrayWidget.qml) unconditionally activates an item on left click. Open its menu when `onlyMenu` is true, preserve ordinary activation for other items, and close or retarget the menu when its source item disappears. Exercise nested menus, disabled entries, toggles, and app exit with an open menu. [SystemTrayItem](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.SystemTray/SystemTrayItem/).

### Drive Wi-Fi connection from the native result

[WifiPage.qml:131](modules/quickSettings/pages/WifiPage.qml) can request a password page and also start a connection without it. That allows a deferred native attempt and the explicit password attempt to race. Start an attempt against the chosen native network, handle the `NoSecrets` result, and offer `connectWithPsk()` for the documented WPA-Personal and SAE security types. Preserve saved and open-network paths, show terminal failures, and distinguish unsupported enterprise authentication from a missing PSK. Keep the selected network identity across page transitions and clear stale attempts on cancellation or adapter replacement. Also normalize strength in one place. The flow from [NetworkService.qml:110](services/NetworkService.qml) to [WifiPage.qml:68](modules/quickSettings/pages/WifiPage.qml) can interpret an integer 1% as a full-strength fractional value. [Network](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/Network/), [WifiNetwork](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/WifiNetwork/).

### Make anchored popups use the anchor's screen coordinates

[QsPopupWindow.qml:35](components/QsPopupWindow.qml) feeds `mapToGlobal()` coordinates directly into screen-local layer margins, without assigning the popup to the anchor's output. [TrayWidget.qml:232](components/TrayWidget.qml) does the same for [TrayMenu.qml:38](components/TrayMenu.qml). On monitors with a nonzero origin, that can push a popup to the wrong edge. The volume tooltip already assigns the host screen and subtracts both offsets in [QuickSettingsButton.qml:271](modules/quickSettings/QuickSettingsButton.qml). Reuse that geometry rule, clamp both edges against the full outer window size, and track anchor or screen changes while open. Use `QsWindow.window` to resolve the anchor's actual window and `windowTransform` when reacting to its movement.

Pilot `PopupWindow` with `PopupAnchor.item`, an edge and gravity on a simple bar popup. Native `grabFocus` dismisses immediately on an outside click. Keep the custom layer window and `HyprlandFocusGrab` wherever the close animation or layer policy requires control over dismissal. The shared layer popup also needs an input region around its visible card so the unused part of its 650–700 px surface can pass input through. [PopupWindow](https://quickshell.org/docs/v0.3.2/types/Quickshell/PopupWindow/), [PopupAnchor](https://quickshell.org/docs/v0.3.2/types/Quickshell/PopupAnchor/), [QsWindow.mask](https://quickshell.org/docs/v0.3.2/types/Quickshell/QsWindow/#prop.mask), [Region](https://quickshell.org/docs/v0.3.2/types/Quickshell/Region/).

### Preserve notification semantics across reload and expiry

[NotificationService.qml:75](services/NotificationService.qml) enables `keepOnReload` and treats every delivered notification as fresh. Use `lastGeneration` to restore history without replaying toasts. Respect `transient` by keeping those notifications out of persistent history and releasing them after their display lifetime or promptly under DND. [NotificationService.qml:141](services/NotificationService.qml) computes age from `new Date()` without a reactive clock, so the displayed age can stay at “now.” Store arrival time once and format history rows against a minute clock while the history is visible. If exact ages must survive reload, carry over timestamps separately. [NotificationServer](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Notifications/NotificationServer/), [Notification](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Notifications/Notification/), [SystemClock](https://quickshell.org/docs/v0.3.2/types/Quickshell/SystemClock/).

[NotificationService.qml:78](services/NotificationService.qml) advertises actions and action icons. [NotificationCard.qml:38](modules/notifications/NotificationCard.qml) reads action properties, and its [click handler](modules/notifications/NotificationCard.qml) only dismisses or expires the card. Match advertised capabilities to implemented behavior. If retaining actions, wire default activation and visible buttons through `NotificationAction.invoke()`. Test them alongside links, dismiss, hover pause, replacement, and reload. Quickshell updates same-ID replacements in place, so decide when a replacement should restart its display lifetime. [NotificationAction](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Notifications/NotificationAction/), [notification protocol](https://specifications.freedesktop.org/notification/latest/protocol.html), [v0.3.2 replacement handling](https://github.com/quickshell-mirror/quickshell/blob/v0.3.2/src/services/notifications/server.cpp#L163-L201).

### Make wallpaper and palette application one ordered operation

[WallpaperService.qml:14](services/WallpaperService.qml) persists the requested path before `awww` exits, and [WallpaperSelector.qml:61](modules/wallpaper/WallpaperSelector.qml) starts [theme generation](services/ThemeService.qml) independently. Each 0.3.2 `Process` can coalesce a pending rerun, but the two processes can advance to different requests or succeed independently. Track the active request separately from the next command. Commit the wallpaper only on successful completion, and queue the matching Matugen job with a clear policy for superseded work. Surface failure while retaining the last confirmed result for each operation. Handle failed startup as well as nonzero exits. Use `Process.exec()` only when starting an idle job in this flow, because it terminates an active invocation. Test with substitute commands that delay, fail to start, or fail after starting. [Process](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/Process/), [v0.3.2 implementation](https://github.com/quickshell-mirror/quickshell/blob/v0.3.2/src/io/process.cpp#L248-L275).

### Give each shell instance its own writable state

[StateService.qml:11](services/StateService.qml) hardcodes the default configuration path, so a separate `qs -p` checkout can read or write the live shell's state. Put mutable state under `Quickshell.statePath("state.json")`, resolve packaged defaults/assets from `Quickshell.shellDir`, and migrate existing state once. Choose a stable `StateDir` only for the installed shell if launch paths or symlinks vary. Treat [GrayscaleService.qml:16](services/GrayscaleService.qml) as a config asset path. Coordinate any relocation of [ThemeService.qml:48](services/ThemeService.qml) with the [Matugen template destination](../matugen/config.toml).

Keep the existing `FileView` atomic writes and protection for unknown keys. A pending external edit can be skipped by the direct destruction flush in [StateService.qml:24](services/StateService.qml). Define a single state owner or merge the latest disk state before flushing local edits. Distinguish missing and invalid files, and preserve the last valid theme on transient parse failure. Consider `JsonAdapter` for a stable, owned schema where round-tripping extension keys is covered by tests. [Quickshell paths](https://quickshell.org/docs/v0.3.2/types/Quickshell/Quickshell/), [FileView](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/FileView/), [JsonAdapter](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/JsonAdapter/), [changelog](https://quickshell.org/changelog/#v030).

### Keep logout scoped to the current graphical session

[PowerService.qml:81](services/PowerService.qml) falls back from a legacy `hyprctl dispatch exit` to `loginctl terminate-user`, which can close every session belonging to the account. Select a logout command for the running compositor, such as a configured Hyprland shutdown helper or a session-scoped logind request with an explicit session ID. The current Hyprland config uses Lua. Route failures back to the overlay, which currently hides immediately for every action. If the lock helper must survive a shell reload, launch it independently of the QML process lifecycle and verify that lock still works across reload. [Hyprland dispatchers](https://wiki.hypr.land/configuring/core/dispatchers/), [loginctl](https://www.freedesktop.org/software/systemd/man/latest/loginctl.html), [Process](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/Process/).

## P2 · Less background work and more predictable UI

### Scope radio discovery to demand

[QuickSettingsWindow.qml:19](modules/quickSettings/QuickSettingsWindow.qml) acquires a Wi-Fi scan session for the whole window, including the dashboard. [NetworkService.qml:33](services/NetworkService.qml) retains the scan request flag across intents. Acquire demand from the Wi-Fi page and any deliberate connection flow that still needs it. Clear demand on page exit, error, cancellation, radio disable or adapter replacement. Prefer the native network model and scan timestamps over extra polling. Validate the recovery path after NetworkManager restarts, which is covered by a 0.3.2 upstream fix. [Networking](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/Networking/), [WifiDevice](https://quickshell.org/docs/v0.3.2/types/Quickshell.Networking/WifiDevice/), [changelog](https://quickshell.org/changelog/#v032).

[BluetoothPage.qml:45](modules/quickSettings/pages/BluetoothPage.qml) waits 300 ms after requesting power and then toggles discovery. Use explicit start and stop intent against the native adapter state, with the page or active request owning that intent. Handle power transitions, adapter changes, and page leave. Display the documented device name and separate pairing from connection, including pending and cancellation if supported. Keep a separate scan timeout only if the intended UX limits scan duration. [BluetoothAdapter](https://quickshell.org/docs/v0.3.2/types/Quickshell.Bluetooth/BluetoothAdapter/), [BluetoothDevice](https://quickshell.org/docs/v0.3.2/types/Quickshell.Bluetooth/BluetoothDevice/).

### Track audio objects where they are used and read native playback position

[AudioService.qml:15](services/AudioService.qml) binds all non-stream audio nodes, with per-node change listeners, while the bar primarily needs the default sink and source. Keep always-on tracking for those defaults and gate non-default details behind the Audio page or another visible consumer. Use readiness checks after PipeWire restart or hotplug. [AudioService.qml:94](services/AudioService.qml) guesses several port fields, while [AudioPage.qml:289](modules/quickSettings/pages/AudioPage.qml) gates an input-port picker on a list the service never fills. Remove the unreachable path or load verified port data on demand from the existing external audio tooling. Preserve profile and route behavior for hardware that needs it. [PwObjectTracker](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Pipewire/PwObjectTracker/), [PwNode](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Pipewire/PwNode/), [PwNodeAudio](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Pipewire/PwNodeAudio/).

[MprisService.qml:80](services/MprisService.qml) maintains a local elapsed-time estimate even though 0.3.2 exposes the current position on each read. Sample native position using the existing visibility gate, including an immediate refresh on open. Keep an optimistic seek only while a supported seek is in flight, and let the native position account for playback rate. Use `dbusName` for player identity and `dbusName` plus `uniqueId` for track transitions. Verify seek, pause, 2× playback, track changes and player exit. [MprisPlayer](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Mpris/MprisPlayer/).

[MprisService.qml:148](services/MprisService.qml) rebuilds its player projections from both model notifications and observer creation/removal. Use one coalesced update and let the observer `Instantiator` consume `Mpris.players` directly. [NetworkService.qml:221](services/NetworkService.qml) can similarly use the selected device's native networks model for observers, keeping the sorted projection for presentation. [ObjectModel](https://quickshell.org/docs/v0.3.2/types/Quickshell/ObjectModel/).

### Make OSD readiness, suppression, and placement explicit

[shell.qml:67](shell.qml) arms audio and brightness OSD after a fixed 800 ms. Seed the baseline from the volume-known and initial backlight-read states, and reseed when the device changes. [QuickSettingsWindow.qml:31](modules/quickSettings/QuickSettingsWindow.qml) and [QuickSettingsButton.qml:257](modules/quickSettings/QuickSettingsButton.qml) both write a single suppression flag, so one window or wheel timer can release suppression held by another. Give each consumer an owner token and remove it on close or destruction. Carry the host `ShellScreen` with the OSD anchor, and replace the positive-coordinate sentinel in [OsdOverlay.qml:120](modules/osd/OsdOverlay.qml) so negative output origins are valid. [QsWindow](https://quickshell.org/docs/v0.3.2/types/Quickshell/QsWindow/), [Hyprland](https://quickshell.org/docs/v0.3.2/types/Quickshell.Hyprland/Hyprland/).

### Follow the Polkit challenge lifecycle

[PolkitService.qml:14](services/PolkitService.qml) already uses the native agent. [PolkitOverlay.qml:486](modules/polkit/PolkitOverlay.qml) gates submission on a nonempty string and uses a fixed delay for focus. Drive focus and submission from `AuthFlow.isResponseRequired` and clear local responses at challenge boundaries, including when a second prompt arrives. The overlay's success timer in [PolkitOverlay.qml:55](modules/polkit/PolkitOverlay.qml) competes with [the loader's active-flow lifetime](shell.qml). Keep any completion feedback outside the modal grab, or remove it if it is redundant. Test canceled, failed, successful and multi-step flows without logging responses. [PolkitAgent](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Polkit/PolkitAgent/), [AuthFlow](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.Polkit/AuthFlow/), [v0.3.2 flow completion](https://github.com/quickshell-mirror/quickshell/blob/v0.3.2/src/services/polkit/agentimpl.cpp#L144-L166).

### Keep hardware telemetry tied to the selected device

[BrightnessService.qml:107](services/BrightnessService.qml) discovers a backlight for readback, while the write command leaves device selection to `brightnessctl`. Pass the selected backlight device and class, keep the existing write coalescing and readback, and handle write errors. The fallback poll in [BrightnessService.qml:229](services/BrightnessService.qml) disables after one watcher event. Test external brightness changes and resume on the actual hardware, then use backlight uevents or retain a slow watchdog where events are incomplete. Keep permission-aware writes through `brightnessctl`. The daemon start shell in [BrightnessService.qml:288](services/BrightnessService.qml) can move to the graphical session's service lifecycle, with Quickshell controlling its temperature. [Kernel backlight interface](https://www.kernel.org/doc/html/latest/gpu/backlight.html), [brightnessctl](https://github.com/Hummer12007/brightnessctl), [hyprsunset](https://wiki.hypr.land/hypr-ecosystem/user/hyprsunset/).

[SystemMonitorService.qml:151](services/SystemMonitorService.qml) starts sensor detection on construction and [runs an NVIDIA probe](services/SystemMonitorService.qml) even when its GPU meter is off. Discover available devices without waking the driver where possible and run the vendor query only while the GPU meter is enabled and visible. [SystemMonitorService.qml:495](services/SystemMonitorService.qml) accepts every result row, so the last GPU wins. Select a stable GPU identifier and discard results from disabled or superseded requests. Represent unavailable utilization and temperature independently. Reset CPU and network baselines on reactivation and compute per-interface network deltas to handle hotplug and counter resets. Keep the existing visible-only `FileView` reads and slower disk interval. [FileView](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/FileView/), [Process](https://quickshell.org/docs/v0.3.2/types/Quickshell.Io/Process/).

[BatteryService.qml:28](services/BatteryService.qml) falls back through duplicate UPower rates and sensor properties that remain at zero. Check `UPower.displayDevice.ready`, report its signed battery flow with a battery-specific label, and represent unavailable AC/system draw explicitly. A chart of battery flow can use state changes for additional samples, while keeping the existing time-based cadence if it is part of the intended history. [UPowerDevice](https://quickshell.org/docs/v0.3.2/types/Quickshell.Services.UPower/UPowerDevice/).

### Let workspace objects drive the bar

[Workspaces.qml:93](components/Workspaces.qml) repeatedly rebuilds and sorts a workspace ID list after broad raw events. Filter the native, already sorted workspace model while keeping workspace objects as delegate identities. Use [`workspace.activate()`](components/Workspaces.qml) in place of the current legacy dispatch string. The 0.3.2 implementation selects the Lua dispatcher when appropriate. Decide whether the bar should mirror workspace IDs or list only workspaces assigned to its monitor before replacing the current 100-ID bins. Simplify the raw-event handling and delayed title refresh in [ActiveWindow.qml:33](components/ActiveWindow.qml) around the typed active toplevel and workspace, checking blank desktops and keeping a targeted fallback for special-workspace transitions if still required. [Hyprland](https://quickshell.org/docs/v0.3.2/types/Quickshell.Hyprland/Hyprland/), [HyprlandWorkspace](https://quickshell.org/docs/v0.3.2/types/Quickshell.Hyprland/HyprlandWorkspace/), [v0.3.2 implementation](https://raw.githubusercontent.com/quickshell-mirror/quickshell/v0.3.2/src/wayland/hyprland/ipc/workspace.cpp).

### Let the seconds gauge own its clock

[TimeService.qml:13](services/TimeService.qml) wakes every second for a bar clock and dashboard date that display minute-level information. [CalendarWindow.qml:87](modules/calendar/CalendarWindow.qml) needs seconds for its gauge. Use a shared minute clock for bar and date text and a visibility-gated second clock for the calendar gauge. Keep the month grid's day dependency separate from the gauge. ### Baseline before changing the renderer

Closing Quick Settings from another page resets the stack to the dashboard in [QuickSettingsWindow.qml:18](modules/quickSettings/QuickSettingsWindow.qml), then destroys the window through [QuickSettingsButton.qml:241](modules/quickSettings/QuickSettingsButton.qml). Skip that synchronous dashboard construction for a window that is about to unload. Profile the synchronous page loaders and first opens of the more complex [shell overlays](shell.qml) before using `activeAsync` selectively. Reading `LazyLoader.item` mid-incubation forces completion. Guard dependent geometry with an item-ready check and time input readiness, including on a multi-output setup. `Variants` has limitations when nested in async incubation. [LazyLoader](https://quickshell.org/docs/v0.3.2/types/Quickshell/LazyLoader/).

The shared popup draws its card into a fixed-height surface in [QsPopupWindow.qml:64](components/QsPopupWindow.qml). The [Hyprland rules](../hypr/rules.lua) apply blur to that namespace. Test independent compositor clipping via `HyprlandWindow.visibleMask` around the rendered card, with sufficient padding for transforms and shadows. Measure compositor time and verify that animation edges remain visible. `BackgroundEffect.blurRegion` is an option on compositors with protocol support. Keep the input region and render region independently tied to their intended extents. [HyprlandWindow](https://quickshell.org/docs/v0.3.2/types/Quickshell.Hyprland/HyprlandWindow/), [BackgroundEffect](https://quickshell.org/docs/v0.3.2/types/Quickshell.Wayland/BackgroundEffect/).

[NotificationOverlay.qml:11](modules/notifications/NotificationOverlay.qml) repeats the active toast list on every screen and grows each surface to the entire burst. Bound visible toasts and decide whether they should mirror or target the focused output. Keep [history's existing bound](services/NotificationService.qml), but measure retained memory after image-heavy bursts because live notifications can own decoded pixmaps. In [NotificationCard.qml:174](modules/notifications/NotificationCard.qml), use asynchronous decoding for local images where appropriate and a separately gated fallback so assigning a fallback source cannot overwrite the live source binding. Profile fixed-size icons before keeping mipmaps. [Notification implementation](https://github.com/quickshell-mirror/quickshell/blob/v0.3.2/src/services/notifications/notification.cpp#L124-L157), [Image](https://doc.qt.io/qt-6/qml-qtquick-image.html).

[SystemMonitorWindow.qml:198](modules/systemMonitor/SystemMonitorWindow.qml) repaints a CPU Canvas during the usage animation, redrawing the gauge ticks, while [SystemMonitorWindow.qml:327](modules/systemMonitor/SystemMonitorWindow.qml) rebuilds two sampled wave paths every 80 ms while visible. If profiling shows measurable overhead, reuse static gauge geometry with a declarative arc and make the separator static or animate a single shader parameter. [Canvas](https://doc.qt.io/qt-6/qml-qtquick-canvas.html), [Shape](https://doc.qt.io/qt-6/qml-qtquick-shapes-shape.html).

The [wallpaper picker](modules/wallpaper/WallpaperSelector.qml) in this worktree already limits decodes to the viewport and a small neighborhood, uses fixed list geometry, and draws each slice in one shader pass. The earlier isolated 1,409-image comparison measured median peak process RSS of 465 MiB before and 357 MiB after and list readiness of 133 ms before and 101 ms after. That comparison used offscreen Mesa software OpenGL. Use this implementation as the starting point and measure a cold open, rapid navigation, filtering and close on the actual Wayland backend before allocating more work here. If decode remains dominant, prototype a bounded on-demand thumbnail cache with file-change invalidation. Preserve rescans for files copied with older timestamps. The QSB is a required runtime asset. Record its regeneration command, and decide explicitly whether to provide a plain-image fallback for Qt Quick's software scene graph. [Image](https://doc.qt.io/qt-6/qml-qtquick-image.html), [ListView](https://doc.qt.io/qt-6/qml-qtquick-listview.html), [ShaderEffect](https://doc.qt.io/qt-6/qml-qtquick-shadereffect.html), [Qt Quick profiling](https://doc.qt.io/qt-6/qtquick-profiling.html).

[WallpaperSelector.qml:45](modules/wallpaper/WallpaperSelector.qml) filters the same per-scan row objects. If large filters show up in the QML profile, test explicit identity comparison in the [model](modules/wallpaper/WallpaperSelector.qml) to avoid deep comparisons between distinct rows, and skip forced layout/repositioning when membership and selection stay unchanged. [ScriptModel](https://quickshell.org/docs/v0.3.2/types/Quickshell/ScriptModel/).

## P3 · Tooling and shared conventions

- **Use the 0.3.2 language-server workflow.** Add a local, ignored `.qmlls.ini` next to [shell.qml](shell.qml) so Quickshell can populate the runtime import paths. Establish a `qmllint` baseline with a real `qs` root and the installed Quickshell QML modules. This audit ran `qmllint` 6.12.0 across 65 QML files with a temporary `qs` import alias. It reported 163 warnings and 3 informational diagnostics, including 11 layout-positioning warnings.
